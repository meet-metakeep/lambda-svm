## Configure Lambda Project

### Run this project

In the Frontend folder, run below commands. 

            npm install
            npm run dev

These both command will start the server on port 3000 for UI. 


In the backend folder, run below commands. 

        npm install
        npm start

This will start the backend server on port 3001. 



### Env variables

In the backend and frontend folder run below command separately. And configure your variables from console.metakeep.xyz

        cp env.example .env
